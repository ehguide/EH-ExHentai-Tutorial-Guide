## 🛠️ 第二步：填写账户注册信息

按照页面提示，依序填写以下字段即可完成注册（无需填写生日）：

* **Username（用户名）：** 登录网站使用的账号，**注意不能与他人重复**。
* **Display Name（昵称）：** 在画廊或论坛公开显示的名称，**同样不能与他人重复**。
* **Password / Confirm Password（密码与重复密码）：** 设置你的登录密码，并在下方再次输入确认。
* **Email / Confirm Email（邮箱与重复邮箱）：** 填入未被使用的邮箱并重复确认（支持虚假邮箱，切勿使用 QQ 邮箱）。
