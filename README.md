## 📌 注册前准备工作

在开始注册前，请确认以下基本环境：
1. **网络工具：** 需自备网络加速工具（建议使用纯净的欧美节点，如美国 IP）。
2. **浏览器选择：** 建议使用 Chrome、Edge 或 Safari 浏览器的**无痕模式（Incognito Window）**。

## 🛠️ 第一步：前往官方注册页面

1. 开启网络工具后，在浏览器无痕模式中打开官方注册链接：`https://forums.e-hentai.org/index.php?act=Reg`
2. 页面打开后，滑动到底部勾选同意服务条款，点击右下角 **“Submit Form”** 按钮提交。

## 🛠️ 第二步：填写账户注册信息

注册表单非常简单，只需填写以下核心字段即可（无需复杂验证）：

* **Username（用户名）：** 随意设置，注意**不要与别人重复**。
* **Password / Confirm（密码）：** 设置你的登录密码并再次确认。
* **Email Address（邮箱）：** 只要该邮箱未被注册过即可，**填假的邮箱也能通过**！⚠️ *注意：请勿使用 QQ 邮箱，系统不支持。*
* **Birth Date（生日）：** 填入你的出生日期（Day / Month / Year），注意年龄需满 18 岁。
* **Security Code（安全验证码）：** 按照右侧图片提示输入对应的字符。

## 🛠️ 第三步：进入表站与解锁里站权限

1. 提交成功后，先尝试登录表站（`e-hentai.org`），确认能够正常看到搜索界面与封面。
2. 接下来打开新标签页尝试访问里站：`https://exhentai.org`
3. **关于里站报错：** 
   * 若访问里站出现 **熊猫图（Panda Error）** 或大面积白屏，说明当前使用的网络 IP 节点属于公共节点（被系统风控拦截），或新注册账号尚未获得里站访问权限。

## ⚠️ 常见问题排查 (FAQ)

### Q1: 为什么点击提交提示“IP Address Blocked”？
> **答：** 说明你当前的节点 IP 被 E站 系统拦截了。请尝试更换纯净的节点或切换浏览器无痕模式重试。

### Q2: 进 ExHentai（里站）一直是熊猫图或白屏怎么办？
> **答：** 新注册账号通常无法直接进里站。一般需要使用纯净 IP 养号等待，或者通过导入有效 Cookie 方式才能直接进入。
